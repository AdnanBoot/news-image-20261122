A deterministic Pillow program rendering a one-image summary of the world news of Sunday 22 November 2026 as a 1024x1024 broadsheet front page (`entry.png`).

## How to Run

- `python3 draw.py` regenerates `entry.png` deterministically beside the script.
- `python3 main.py` copies `entry.png` to the output directory specified by `MAKEFUN_OUTPUT_DIR` (default `/output`) and verifies the SHA-256 digest of the copy.
